Reelink

Groups duplicate Series records by assigning a shared Jellyfin presentation key, and merges repeated movies and episodes into version groups. It never deletes media files or library records.

Comma-separated provider names. The first shared ID determines the stable series group key. Default: Tvdb,Tmdb,Imdb.
Use 1 for ordinary duplicate repair. Raise this to 2 for stricter matching when both copies have multiple IDs.
The task can always be run manually from Dashboard → Scheduled Tasks.
Log detected series groups without changing presentation keys. Also applies to selected series merges from this page.

Preview and merge

Scan for duplicates, review each proposed group with its titles and matched IDs, deselect anything you do not want merged, then apply only your selection.

Split

Splitting separates series previously grouped by Reelink, and separates movie and episode version groups back into individual items. These actions apply immediately.
